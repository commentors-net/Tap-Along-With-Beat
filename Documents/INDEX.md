## ?? Core Systems Documentation

### Manager Systems
- **GameManager**: Main game flow and state management
- **AudioManager**: Music synchronization and sound effects
- **InputManager**: Touch/mouse input handling
- **ScoreManager**: Scoring, combos, and accuracy
- **UIManager**: UI panels and displays
- **PlayerDataManager**: Save/load system

### Gameplay Systems
- **NoteController**: Individual note behavior
- **NoteSpawner**: Beat map-driven note spawning
- **GameplayController**: Level flow and transitions
- **EffectsManager**: Visual effects and feedback

### Utilities
- **GameUtilities**: Helper functions
- **Singleton**: Base class for managers
- **GameConfig**: ScriptableObject settings
- **BeatMapCreator**: Beat map creation tool

## ?? Unity Components Reference

### Required Unity Components
- **Audio Source**: For AudioManager
- **Canvas**: For UIManager
- **EventSystem**: For UI interaction
- **Collider 2D**: For notes
- **Rigidbody 2D**: For note physics

### Script Execution Order
Unity defaults work fine, but if needed:
1. GameManager (-100)
2. AudioManager (-50)
3. InputManager (-50)
4. Other managers (0)
5. Gameplay scripts (0)

## ?? Conventions Used

### Code Style
- PascalCase for public members
- camelCase for private members
- _camelCase for private fields
- XML comments for public APIs

### Naming Conventions
- Managers: `XxxManager`
- Controllers: `XxxController`
- Interfaces: `IXxx`
- Events: `OnXxx`

### Scene Organization
- Managers at root level
- UI under Canvas
- Gameplay objects grouped
- Prefabs instantiated at runtime
